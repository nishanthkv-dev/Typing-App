# Typing Thalaiva — Android (Capacitor)

A native Android wrapper around the **Typing Thalaiva** web app, packaged using [Capacitor](https://capacitorjs.com/).

## Quick start (local development)

```bash
# 1. Install Node deps
npm install

# 2. Add the Android platform (first time only)
npx cap add android

# 3. Sync web assets into the Android project
npx cap sync android

# 4. Open in Android Studio (optional)
npx cap open android

# 5. Build a debug APK from the command line
cd android && ./gradlew assembleDebug
# APK → android/app/build/outputs/apk/debug/app-debug.apk
```

## GitHub Actions CI

Push to `main` or `master` and the **Build Debug APK** workflow will automatically:
1. Install Node 20, Java 17, and the Android SDK
2. Run `npx cap sync android`
3. Compile a debug APK via Gradle
4. Upload `app-debug.apk` as a downloadable workflow artifact (kept 14 days)

Navigate to **Actions → Build Debug APK → latest run → Artifacts** to download and sideload on your device.

## Features wrapped natively
| Feature | Implementation |
|---|---|
| Hardware back button | Capacitor `App.addListener('backButton', …)` already in `index.html` |
| Soft keyboard handling | `Keyboard.resize = body` + viewport meta in `index.html` |
| PDF download | `jsPDF.save()` — triggers Android download manager |
| Share image | `navigator.share()` with `File` → Android share sheet |
| Offline use | All assets bundled; no network required after install |
